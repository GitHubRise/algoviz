## 概述

把表达式画成曲线，并在同一条时间轴上让参数 `t` 扫过 0..1，得到「行波」效果。
读者是要改函数模块的人；前置是 `300002`（表达式）与 `300003`（坐标与采样）。
读完能回答：为什么滚轮缩放不会把圆压扁、为什么 `tan(x)` 不会出现竖直长线。

## 控件

| 控件 | 类型 | 行为 |
|---|---|---|
| 曲线表达式 | 文本框 | 输入即时校验；非法时边框标红并在下方显示原因；直接 Ctrl+V 会走粘贴规范化 |
| 曲线类型 | 下拉（每条一个） | `y = f(x)` / `F(x,y) = 0` / `r(θ)` / `x(u), y(u)` / `z = f(x,y)` / `f(z)`，切换后立即用新口径求值 |
| 参数方程第二行 | 文本框（仅参数方程显示） | `y(u) = …`；与第一行一起校验，任一为空即整条不画 |
| 色块 | 点击 | 显示/隐藏该曲线（不影响其他曲线） |
| 函数库（v0.4） | 分组下拉 + 「填入曲线」 | 21 个分组、约 61 个预设：常数/一次/二次/三次/反比例/幂/指数/对数/幂指/对勾/三角/双曲/反函数/阶乘与伽马/复合/分段/二元/隐函数/极坐标/参数方程/复变 |
| 添加曲线 / 粘贴公式 | 按钮 | 最多 5 条；粘贴按钮读剪贴板，被拒时提示改用 Ctrl+V |
| 网格与坐标轴 | 开关 | 关闭后只画曲线与轴 |
| 切线（在 x₀ 处） | 开关 + 滑杆 | 滑杆范围 -10..10，步长 0.05；只对显式曲线生效 |
| 定积分填充 | 开关 | 只对显式曲线生效；两条虚线标出 a、b |
| 导数曲线 f′ | 开关（v0.3） | 对显式曲线叠加 `f′(x)` 虚线（中心差分），与曲线同色半透明 |
| 标注零点与极值 | 开关（v0.3） | 零点画空心圆，极值画菱形并标 `max/min (x, y)` |
| 标注交点 | 开关（v0.4） | 两两求 `f1 - f2` 的零点，画圆环并标 `(x, y)`，最多 8 个 |
| 反函数 | 开关（v0.4） | 把 `(x, f(x))` 反射成 `(f(x), x)` 画虚线（关系图，可多值） |
| 参数 a / b（v0.4） | 曲线选择 + 两根滑杆 | 选一条曲线，直接调它的 a（水平）/ b（垂直），范围 -10..10 |
| 积分下限/上限 | 数字输入 | 单位：世界坐标；上下限颠倒会自动交换 |
| 重置视图 / 适应 y 轴 / 复位曲线参数 | 按钮 | 「适应 y 轴」只看显式曲线；「复位曲线参数」把所有 a、b 清零 |
| 复制分享链接 | 按钮（v0.3） | 把曲线表达式/类型/a、b/可见性编码进 URL hash 并写剪贴板 |
| 导出 PNG | 播放器右侧按钮（v0.3） | 三个模块通用，导出当前画布的 device-pixel 图 |

## 手势

| 手势 | 结果 |
|---|---|
| 滚轮 | 以光标为锚点缩放，`factor = exp(-Δy × 0.0015)` |
| 拖到曲线上 | 抓取该曲线，左右拖改 `a`、上下拖改 `b`；画布右上角实时显示数值 |
| Shift + 拖动曲线 | 只改垂直偏移 `b` |
| 在空白处拖动 | 平移视图；光标变 `grabbing` |
| 双击 | 回到原点与默认比例 |
| 移动 | 十字准星 + 显式曲线的 `f(x)` 读数框；悬停在曲线上时光标变 `grab` |
| 移出画布 | 读数框消失，恢复底部提示 |

拖动语义：`a`/`b` 是曲线的偏移参数。表达式里没用到它们时，渲染层直接当平移施加（`f(x-a)+b` 的效果）；表达式里用到了（例如 `sin(x-a)+b`），就完全由公式决定，渲染层不再叠加。隐函数曲线不参与拖动调参——命中检测只对显式、极坐标与参数方程曲线生效。

粘贴：单行会替换当前输入；多行按行填充到后续曲线，必要时自动「添加曲线」。规范化规则见 `docs/300002-表达式解析与求值.md`。

播放器进度即 `t`：`sin(x + 2*pi*t)` 会随进度左右移动。

## 分析标注

| 标注 | 算法 | 说明 |
|---|---|---|
| 零点 | 采样找符号变化，二分收敛 | 只对显式曲线；空心圆 |
| 极值 | 三点比较 + 抛物插值细化 | `max` 标在点上方、`min` 标在下方，附 `(x, y)` |
| 交点（v0.4） | 对 `f1 - f2` 复用零点算法，y 取 `f1(x)` | 只对两条显式曲线；圆环 + `(x, y)`，最多 8 个 |

采样密度随画布宽度变化（`max(240, min(800, W/2))`），只统计当前视窗内的区间。
`x^3` 在 0 处的鞍点不算极值（严格的「比两侧都大/都小」才计）。
交点与零点一样靠符号变化，**相切（偶重根）检不出**，除非切点恰好落在采样格上。

## 绘制顺序

1. 背景 → 2. 细网格 → 3. 主网格 → 4. 坐标轴与刻度 → 5. 曲线（显式/极坐标/隐函数/参数方程/二元等高线） → 6. 反函数 → 7. 导数 → 8. 零点/极值 → 9. 交点 → 10. 积分填充 → 11. 切线 → 12. 悬停读数 → 13. 拖动读数。

标注画在曲线之上，避免被曲线遮住；读数框放最后，保证不被其他图元覆盖。

## 已知限制

| 限制 | 原因 | 何时处理 |
|---|---|---|
| 最多 5 条曲线 | 侧栏高度与颜色区分度 | 需要更多时改成折叠列表 |
| `a`/`b` 之外的自由变量按 0 处理 | 便于先写公式再给参数 | 需要参数滑杆时，把变量表接进侧栏 |
| 隐函数不参与拖动调参 | 命中检测要做最近点搜索，成本高于收益 | 需要时对 F 采样做最近点 |
| 极坐标固定扫 3 圈、参数方程固定扫 2 圈 | 兼顾闭合图形与螺旋 | 需要可变圈数时加曲线级参数 |
| 分析标注只对显式曲线 | 隐函数/极坐标的零点没有「沿 x 排序」的直观含义 | 需要时改成沿弧长排序 |
| 二元函数只画等高线，不画 3D 曲面 | 3D 需要投影与遮挡，是另一个量级 | 需要时单独做 3D 视图 |
| 复变函数是静态域着色 | 每 5px 采一点后放大，拖动/缩放时整体重算，没有缓存 | 需要更顺滑时降分辨率或加脏检查 |
| 分享链接只编码函数模块 | 排序/寻路的「状态」更像操作记录而非结果 | 需要时再扩展 |

## 对外 API 参数

无 HTTP 接口。模块对内的公开面实现 `VizModule`（见 `300001`），不额外导出。

## 方法传参

```ts
class FunctionsModule implements VizModule {
  constructor(ctx: ModuleContext, initial?: string[]);  // 默认 ['sin(x)', '0.15x^2 - 2']
  render(progress: number): void;   // progress 即 t
}

class PlotView {
  constructor(surface: Surface);
  draw(curves: CurveSpec[], opts: PlotOptions): void;
  // CurveSpec: { color, compiled, visible }
}
```

副作用：`activate()` 首次会 `plot.reset()`；`deactivate()` 清空悬停状态。
