## 概述

把表达式画成曲线，并在同一条时间轴上让参数 `t` 扫过 0..1，得到「行波」效果。
读者是要改函数模块的人；前置是 `300002`（表达式）与 `300003`（坐标与采样）。
读完能回答：为什么滚轮缩放不会把圆压扁、为什么 `tan(x)` 不会出现竖直长线。

## 控件

| 控件 | 类型 | 行为 |
|---|---|---|
| 曲线 1 / 2 | 文本框 | 输入即时校验；非法时边框标红并在下方显示原因 |
| 色块 | 点击 | 显示/隐藏该曲线（不影响其他曲线） |
| 示例按钮 | 5 个 | 把当前第二条曲线换成预设表达式 |
| 网格与坐标轴 | 开关 | 关闭后只画曲线与轴 |
| 切线（在 x₀ 处） | 开关 + 滑杆 | 滑杆范围 -10..10，步长 0.05；关闭时滑杆禁用 |
| 定积分填充 | 开关 | 两条虚线标出 a、b，填充曲线与基线之间 |
| 积分下限/上限 | 数字输入 | 单位：世界坐标；上下限颠倒会自动交换 |
| 重置视图 / 适应 y 轴 | 按钮 | 后者在当前 x 视窗内采样 480 点求 y 范围 |

## 手势

| 手势 | 结果 |
|---|---|
| 滚轮 | 以光标为锚点缩放，`factor = exp(-Δy × 0.0015)` |
| 按住拖拽 | 平移；光标变 `grabbing` |
| 双击 | 回到原点与默认比例 |
| 移动 | 十字准星 + 每条可见曲线的 `f(x)` 读数框 |
| 移出画布 | 读数框消失，恢复底部提示 |

播放器进度即 `t`：`sin(x + 2*pi*t)` 会随进度左右平移。

## 绘制顺序

1. 背景 → 2. 细网格 → 3. 主网格 → 4. 坐标轴与刻度 → 5. 曲线 → 6. 积分填充 → 7. 切线 → 8. 悬停准星与读数。

积分与切线画在曲线之上，避免被曲线遮住；读数框放最后，保证不被其他图元覆盖。

## 已知限制

| 限制 | 原因 | 何时处理 |
|---|---|---|
| 最多 2 条曲线 | 侧栏宽度与颜色区分度 | 需要对比 3 条以上时改成可增删列表 |
| `x` 与 `t` 之外的自由变量按 0 处理 | 便于先写公式再给参数 | 需要参数滑杆时，把变量表接进侧栏 |
| 隐函数 / 极坐标 / 参数方程不支持 | 是另一套求值与采样口径 | 另立模块，不塞进现有输入框 |
| 渐变填充只有单色 | 面积填充的语义是「区域」，不是图例 | 保持现状 |

## 对外 API 参数

无 HTTP 接口。模块对内的公开面实现 `VizModule`（见 `300001`），不额外导出。

## 方法传参

```ts
class FunctionsModule implements VizModule {
  constructor(ctx: ModuleContext, initial?: string[]);  // 默认 ['sin(x)', '0.15x^2 - 2']
  render(progress: number): void;   // progress 即 t
}

class PlotView {
  constructor(surface: Surface);
  draw(curves: CurveSpec[], opts: PlotOptions): void;
  // CurveSpec: { color, compiled, visible }
}
```

副作用：`activate()` 首次会 `plot.reset()`；`deactivate()` 清空悬停状态。
