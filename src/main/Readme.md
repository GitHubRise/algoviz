# 正式实现（`src/main/`）

放进入交付物的源码，**不放测试代码与探路脚本**。

| 子目录 | 放什么 |
|---|---|
| `core/` | 与业务无关的基座：播放器、画布封装、DOM 构造、主题 |
| `math/` | 表达式链路：词法、Pratt 解析、闭包编译、内置函数表 |
| `modules/` | 三个可视化模块，各自含 UI 与（排序/寻路的）纯算法 |
| `ui/` | 侧栏控件工厂与播放器条 |
| `app.ts` | 外壳：标签页、rAF 循环、键盘、ResizeObserver |
| `main.ts` | 挂载入口 |
| `styles.css` | 全局样式 |

依赖方向见 `../../docs/300001-总体架构与帧时间轴.md`：外壳 → 时间轴 → 基座；模块只依赖基座与自身算法。

不放：`*.test.ts`（在 `src/test/`）、一次性探针（在 `src/demo/`）、构建产物（`dist/`）。
