# 判定表：排序与寻路（`src/test/`）

> 与测试代码同目录维护，按 [`development-method.md`](../../../../general-policies/general/engineering/development-method.md) 第 3 节执行。
> 每条用例有编号，`*.test.ts` 里的用例名引用编号；编号一旦分配不再复用。

## 约定

- 通过 = 断言全绿且退出码 0；不通过 = 任一断言失败或退出码非 0。
- 反例（标 **R**）必须被拦住才证明校验生效，只测正常路径的表等于废表。
- 帧序列的所有帧长度必须等于输入长度；这是渲染层的前提，长度不一致视为崩溃而非「显示异常」。

## 寻路（`src/main/modules/pathfinding/algorithms.ts`）

网格以行优先索引：`index = y * cols + x`。

| 编号 | 类型 | 输入 | 期望结果 |
|---|---|---|---|
| T-P01 | 正常 | 5×5 空网格，`start=0`，`goal=24`，BFS | `found=true`，`path.length=9`（曼哈顿距离 8 + 起点） |
| T-P02 | 正常 | 同上，A* | `found=true`，`path.length=9` |
| T-P03 | 正常 | 同上，Dijkstra | `found=true`，`path.length=9` |
| T-P04 | 正常 | 同上，DFS | `found=true` |
| T-P05 | 正常 | 任一算法返回的 `path` | 相邻两点曼哈顿距离恒为 1（无跳跃），首点为 `start`，末点为 `goal` |
| T-P06 | 正常 | 任一算法返回的 `path` | 路径中不含任何 `walls` 中的格子 |
| T-P07 | 边界 | `start === goal` | `found=true`，`path=[start]`，`cost=0` |
| T-P08 | 边界 | 目标被墙完全包围 | `found=false`，`path=[]` |
| T-P09 | 边界 | 起点被墙完全包围 | `found=false` |
| T-P10 | 边界 | 网格只有一行（1×7），`start=0`，`goal=6` | `found=true`，`path.length=7` |
| T-P11 | 正常 | 一字墙在中间，仅留一个缺口 | 四种算法都 `found=true`，且路径经过缺口 |
| T-P12 | 正常 | 有墙的网格 | 返回的 `visitedCount > 0` 且在 `(0, cols*rows]` 区间内 |
| T-P13 | **R** | `start` 或 `goal` 越界（如 5×5 网格传 `start=99`） | 抛 `Error`，message 含 `索引越界` |
| T-P14 | **R** | `start` 或 `goal` 落在 `walls` 里 | 抛 `Error`，message 含 `起点或终点在墙内` |
| T-P15 | **R** | `cols <= 0` | 抛 `Error`，message 含 `网格尺寸非法` |
| T-P16 | 正常 | 四个算法跑同一张带墙网格 | 都能终止（不超时），`found` 为布尔值 |
